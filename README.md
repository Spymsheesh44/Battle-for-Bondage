# Battle of Bodange: Python Strategy Game 🇧🇪🛡️

A lightweight, text-based survival strategy game built in Python, inspired by the historical Battle of Bodange in May 1940. 

## The History
During the opening days of WWII, a small contingent of Belgian soldiers known as the *Chasseurs Ardennais* successfully stalled the massive German 1st Panzer Division for an entire day using terrain, demolitions, and sheer grit. 

## Features
* **Object-Oriented Design:** Clean, modular Python code.
* **Resource Management:** Balance your Morale and Ammo to survive 10 grueling hours.
* **Save/Load Functionality:** Uses `json` to save your campaign progress locally.

## How to Play
1. Clone this repository: `git clone https://github.com/YOUR-USERNAME/bodange-game.git`
2. Navigate to the folder: `cd bodange-game`
3. Run the script: `python bodange.py`
